# DANGAN RP — 단간론파 역극 사이트

친구들과 단간론파 스타일 역극(롤플레이)을 하는 사이트입니다.

- **일상 / 조사 파트** — 네이버 카페 같은 게시판. 글을 쓰면 GM이 댓글로 조사 결과를 알려주고, 댓글에 **언령(말탄환)·아이템·모노쿠마 메달**을 붙여 지급합니다.
- **학급재판** — 실시간 채팅. 단간론파식 대화창과 **표정 스프라이트**, 논파, 투표.
- **전자학생수첩** — 학생 명부, 내 캐릭터(메달·스킬·언령·소지품), 교칙, 지도, 알림.
- **매점** — 모노쿠마 메달로 구매, 모노모노 머신(뽑기), 다른 학생에게 선물.
- **캐릭터 고유 스킬** — 캐릭터마다 스킬과 사용 횟수(재판마다 초기화).
- **한 계정으로 캐릭터 여러 명** — 닉네임+비밀번호 계정이라 다른 기기에서도 같은 계정으로 이어서 할 수 있습니다.

## 사용법

### 시작
1. GM이 「새 방 만들기」로 방을 만들고, 상단의 방 코드를 눌러 초대 링크를 복사해 친구에게 보냅니다.
2. 친구는 방 코드 + 닉네임 + 비밀번호로 입장합니다. (처음이면 그대로 계정이 만들어짐)
3. 학생수첩 → 내 캐릭터 → 「+ 새 캐릭터」. 표정 스프라이트 탭에서 이미지를 여러 장 올리고 이름(기본, 웃음, 화남…)을 붙입니다. 첫 번째가 기본 표정입니다.

### 일상 / 조사 (게시판)
- 글쓰기 → 게시판(일상/조사/자유), 작성 캐릭터, 표정, 장소를 고르고 글을 씁니다.
- 댓글과 답글로 캐릭터끼리 대화합니다. 캐릭터를 고르지 않으면 OOC(캐릭터 밖) 댓글이 됩니다.
- **GM**: 조사 글에 댓글을 달 때 「🎁 보상 지급」을 펼쳐 언령 / 아이템 / 메달을 추가하고 받을 캐릭터를 체크하면 바로 그 캐릭터의 학생수첩에 들어갑니다.
- 언령과 소지품은 **그 캐릭터 주인과 GM만** 볼 수 있습니다. 학생수첩에서 다른 캐릭터에게 언령을 공유하거나 아이템을 선물할 수 있습니다.

### 자유시간 · 친밀도
- 캐릭터마다 하루 **자유시간 티켓**(기본 2장)이 있고, GM이 다음 날로 넘기면 다시 채워집니다.
- 학생수첩 → **통신부**에서 상대의 「💞 자유시간」을 누르거나, 글쓰기에서 「💞 자유시간」 게시판을 고르고 상대를 정하면 두 사람의 자유시간 글이 생깁니다. 상대 플레이어가 댓글로 이어서 역극하면 됩니다.
- 자유시간을 보내거나 선물을 주면 친밀도가 오릅니다. 캐릭터 수정에서 정한 **좋아하는 것** 키워드가 선물 이름에 들어 있으면 더 많이 오르고, **싫어하는 것**이면 내려갑니다. (좋아하는 것/싫어하는 것은 본인과 GM만 볼 수 있어요)
- 일정 점수마다 레벨이 오르며 「희망의 조각」 연출이 뜹니다. 통신부에서 학생별 친밀도(◆◆◇◇◇)를 볼 수 있습니다.
- GM 화면에서 점수 규칙, 티켓, 친밀도 직접 조정, 전체 친밀도 표를 관리합니다.

### 학급재판 (실시간)
- GM 화면에서 「학급재판」을 누르면 모두의 화면이 재판장으로 이동합니다.
- 캐릭터와 표정(썸네일 클릭 또는 `Alt+숫자`)을 고르고 발언합니다. 대화창에 타자기 효과로 표시됩니다.
- 발언에서 `{중괄호}`로 감싼 부분은 **약점**이 됩니다. 약점을 클릭 → 캐릭터와 언령을 고르고 「그건 틀렸어!」/「동의한다!」.
  - GM이 발언할 때 「정답 언령」을 정해두면 자동으로 BREAK / 튕겨남 판정, 아니면 GM이 로그에서 직접 판정합니다.
- 대사에 내가 가진 언령 이름이 나오면 노란 점선으로 표시되고, 누르면 그 언령의 설명이 팝업으로 뜹니다.
- 재판에서 언령을 **꺼내면(그 언령을 가진 캐릭터가 대사에 이름을 말하거나, 그 언령으로 논파하면)** 그 언령은 모두에게 공개되어, 가지고 있지 않은 사람도 눌러서 설명을 볼 수 있습니다. GM 나레이션에 언령 이름을 쓰면 그것도 공개됩니다.
- 스킬 탭에서 고유 스킬 발동, 투표 탭에서 **캐릭터별로** 투표합니다. 주사위는 `/r 20` 또는 🎲.

### 지난 이야기 (GM 화면 → 📚 지난 이야기)
카페 등 사이트 밖에서 이미 진행한 챕터가 있다면 여기에 요약이나 원문을 붙여 두세요.
- AI 사건 설계 요청문에 「이미 일어난 일」로 들어가서, 새 사건이 앞 이야기와 모순되지 않고 관계·복선을 이어받습니다.
- 기록마다 「모두 공개」(로그북에서 플레이어도 읽기) / 「GM만」(AI 참고용)을 고를 수 있어요.
- 학원 설정의 **시작 챕터**를 2로 두면 사이트에서의 첫 사건이 「제2장」이 되고, 로그북 챕터 번호도 2부터 매겨집니다.
- 앞 챕터에서 사망한 캐릭터는 캐릭터 관리에서 사망 처리해 주세요.

### 사건 기획 (GM → 🔪 사건 기획)

> **🔒 봉인 모드 (기본값)** — GM도 플레이어로 참여할 때 쓰세요.
> - 추첨 결과(피해자·흑막)와 사건 내용이 GM 화면에도 나오지 않고, 사건 파일이 들어오는 순간 당사자 학생수첩으로 메일이 자동 발송됩니다. 사건 메일과 그 알림은 받은 캐릭터 주인만 볼 수 있어요(GM 포함).
> - 요청문과 붙여넣은 답변은 사이트에서 흐리게 가려집니다. 단, claude.ai 채팅 화면에 나오는 답변은 가릴 수 없으니 답변이 나오는 동안 화면을 보지 말고, 끝나면 코드 블록의 복사 버튼만 누르세요. 완전히 안 보려면 API 키로 「AI로 바로 생성」을 쓰면 됩니다.
> - 시체 발견 뒤에는 피해자, 모노쿠마 파일, 단서 목록(핵심 여부는 숨김)만 열립니다.
> - 재판은 「사건」 탭의 **다음 논점 내기**로 진행하면 정답을 모르는 채 자동으로 BREAK 판정이 됩니다.
> - 투표 결과를 공개하면 모노쿠마가 정답 여부와 진짜 흑막을 발표하고 봉인이 풀립니다. (「진상 공개」 버튼으로 언제든 직접 풀 수도 있어요)

1. **추첨**: 피해자와 흑막을 랜덤으로 뽑습니다. 「직접 지정하기」로 정할 수도 있어요(봉인 모드에서도 가능 — 지정한 사람만 알고 다른 GM에게는 봉인). GM 본인의 캐릭터를 빼고 뽑을 수도 있고, 마음에 안 들면 「다시 뽑기」.
2. **사건 파일 만들기**
   - **claude.ai로 (무료)**: 「사건 설계 요청문 복사」 → claude.ai 새 채팅에 붙여넣기 → 답변 전체를 「붙여넣기」 칸에 넣고 「불러오기」.
     요청문에는 캐릭터 프로필·스킬·소지품·친밀도·지난 이야기·최근 역극 기록·동기 발표·매점 상품·야간 출입 제한·추첨 결과·출력 형식이 들어 있습니다. AI는 사건을 쓰기 전에 「개연성 점검」(동기·수단·기회·목격자·결정적 실수·우연 여부)을 먼저 하고, 그 내용은 사건 파일에서 볼 수 있어요. 결과가 마음에 안 들면 그 채팅에서 고쳐 달라고 한 뒤 다시 붙여넣으면 됩니다.
   - **AI로 바로 생성 (선택)**: 서버에 `ANTHROPIC_API_KEY` 환경변수를 넣으면 버튼 하나로 만들어집니다. (모델은 `CASE_AI_MODEL`로 바꿀 수 있음, 기본 `claude-opus-5-5`)
   - 사건 파일: 개요·동기·수법·타임라인·모노쿠마 파일·비밀 메일·단서(핵심/보조/미스디렉션)·재판 논점과 정답·GM 메모. 정답 언령이 단서 목록에 없는 등 문제가 있으면 경고가 뜨고, JSON으로 직접 고칠 수도 있어요.
3. **메일 발송**: 흑막·피해자 캐릭터의 학생수첩 **메일함**으로 비밀 메일이 갑니다. 흑막은 사건 경위와 행동 지침을 받고, 피해자는 흑막 단서가 새지 않도록 "당신이 피해자입니다"라는 고정 문구만 받습니다. 공개되는 모노쿠마 파일에 흑막 이름이 들어 있으면 자동으로 지워집니다.
4. **조사**: 플레이어의 조사 글을 보고 사건 파일의 단서를 「지급」합니다. 같은 단서는 같은 언령으로 묶여요.
5. **시체 발견**: 피해자 사망 처리 + 모노쿠마 파일이 담긴 공지가 올라가고 조사 파트로 바뀝니다.
6. **학급재판**: 재판 화면의 GM 전용 「사건」 탭에서 논점을 「발언칸에 넣기」로 바로 쓰면 정답 언령까지 설정됩니다.

GM은 학생수첩 → 메일에서 아무 캐릭터에게나 메일을 직접 보낼 수도 있습니다.

### 학급재판 마무리
- **🧩 클라이맥스 추리** (GM → 재판 화면 「사건」 탭): 사건을 재구성한 컷이 섞여서 나오고, 모두가 같은 판에서 함께 순서를 맞춥니다. 틀리면 몇 컷이 제자리인지 알려 주고, 맞히면 모두의 화면에 「이게 사건의 전말이다!」 연출이 재생됩니다. 컷에는 흑막 이름 대신 「범인」만 쓰이고, 정답 순서는 서버만 알아서 봉인 모드에서도 쓸 수 있어요.
- **⚔ 반론 쇼다운** (재판 입력줄의 「⚔ 반론」): 누구든 상대를 지목해 1:1로 반론 대사를 겁니다. 상대가 {약점}을 언령으로 「베면」 반론한 쪽이 「수긍한다(BREAK)」나 「아직이야!」를 고릅니다. 정답을 시스템이 몰라도 되니 흑막 플레이어가 버틸 때 쓰기 좋아요.
- **⚡ 오시오키** (흑막 공개 후 「사건」 탭): GAME OVER → 처형 제목 → 장면들 → THE END 순서로 전체 화면 연출이 재생되고, 흑막은 사망 처리됩니다.
- 새로 만드는 사건 파일에는 클라이맥스 컷과 오시오키 연출이 함께 들어갑니다. 예전 사건 파일은 타임라인과 기본 처형 문구로 대신 진행돼요.

### 사운드 (GM 화면 → 🎵 사운드)
- 슬롯마다 가지고 있는 음원 파일을 넣으면 상황에 맞게 자동으로 나옵니다.
  - **BGM**: 로비, 일상, 조사, 학급재판, 반론 쇼다운, 클라이맥스 추리, 오시오키
  - **효과음**: 그건 틀렸어!, 동의한다!, BREAK, 튕겨남, 시체 발견, 모노쿠마 방송, 투표, 정답/오답, 반론, 베기, 스킬, 희망의 조각, 메일, GAME OVER
- 파일은 서버 컴퓨터의 `data/audio` 폴더에 저장되고 git과 방 백업에는 들어가지 않습니다. 폴더에 `trial.mp3`처럼 슬롯 이름으로 직접 넣어도 돼요. (mp3, ogg, wav, m4a, flac)
- 각자 상단의 🔊 버튼으로 BGM/효과음 음량과 음소거를 정합니다. 브라우저 정책상 화면을 한 번 클릭해야 소리가 나기 시작해요.

### 하루 흐름
- GM 화면 → 진행의 **☀️ 아침 방송(다음 날)** · **🌤 낮** · **🌙 야간 방송**. 아침 방송은 날짜를 넘기고 자유시간 티켓을 채웁니다. 상단에 지금 시간대가 표시돼요.
- 학원 설정의 **야간 출입 금지 장소**는 야간 방송 뒤에 그 장소로 글을 쓸 수 없게 잠깁니다 (GM은 예외). 학생수첩 지도에 🔒로 표시돼요.
- **📼 동기 발표**: 모두에게 방송하고, 캐릭터마다 다른 「동기」를 학생수첩 메일로 보냅니다.
- 친밀도가 **최대 레벨**이 되면 두 캐릭터에게 「유대 — 상대 이름」 스킬(재판당 1회)과 특별 메일이 갑니다. (자유시간 설정에서 끌 수 있음)

### 알림 · 로그북 · 자동 백업
- **알림**: 내 글에 댓글이 달리거나, 내 댓글에 답글이 달리거나, 누가 `@캐릭터이름`으로 부르면 그 사람에게만 알림이 갑니다. 알림을 누르면 해당 글/재판으로 이동하고, 학생수첩 → 알림에서 「나에게 온 것만」 모아 볼 수 있어요.
- **로그북** (학생수첩 → 로그북): 게시판 글·댓글과 학급재판 로그를 시간순으로 모아 책처럼 보여 줍니다. 「처형」 단위로 챕터가 나뉘고, HTML·텍스트 파일로 저장할 수 있어요. 비밀 메일은 들어가지 않습니다.
- **자동 백업**: 10분마다 바뀐 내용이 있으면 서버 컴퓨터의 `data/backups/<방코드>/`에 자동 저장됩니다 (최근 30개 + 하루 1개씩 14일). 불러오기·재판 로그 비우기·사건/캐릭터 삭제 직전에도 저장돼요. GM 화면 → 플레이어 아래 「자동 백업」에서 목록을 보고 받거나 그 시점으로 되돌릴 수 있습니다. 되돌리기 전 상태도 백업돼서 다시 돌아올 수 있어요.

### GM 화면

## Railway에 올리기 (추천)

1. https://railway.com 에 GitHub 계정으로 가입 → **New Project → Deploy from GitHub repo → `ju3236/Dangan`**.
2. 만들어진 서비스를 누르고 **Settings → Source → Branch**에서 이 사이트가 있는 브랜치를 고릅니다.
3. 서비스 위에서 마우스 오른쪽 클릭(또는 `Ctrl/⌘ + K`) → **Volume 추가**, 마운트 경로는 `/data`.
   - 사이트가 볼륨을 자동으로 알아보고 방 데이터·음원·자동 백업을 전부 볼륨에 저장합니다. 따로 설정할 환경변수는 없어요.
4. **Settings → Networking → Generate Domain** 으로 주소(`https://….up.railway.app`)를 만들고 친구에게 보냅니다.
5. 코드가 바뀌면 GitHub에 올라가는 순간 Railway가 자동으로 다시 배포합니다. 볼륨의 데이터는 그대로 남아요.

- 요금: 처음엔 체험 크레딧이 있고, 계속 쓰려면 Hobby 플랜(월 $5, 사용량 $5 포함)이 필요합니다. 둘이 쓰는 정도면 보통 그 안에서 충분해요.
- 내 컴퓨터에서 쓰던 방을 옮기려면: 내 컴퓨터 GM 화면에서 「방 백업 파일 받기」 → Railway 사이트에서 방을 새로 만든 뒤 「백업 파일 불러오기」. 음원은 Railway 쪽 GM 화면에서 다시 넣어 주세요.
- 음원은 그 방에 로그인한 사람만 받을 수 있게 막혀 있습니다.

## 인터넷에 올리기

실시간 서버(Node.js)가 필요해서 GitHub Pages로는 안 되고, Node 18+ 가 돌아가는 호스팅을 쓰면 됩니다.

**Render (무료)**: https://render.com 가입 → New → Blueprint → 이 저장소 선택 (`render.yaml`로 자동 설정) → 나온 주소를 공유.

> 무료 플랜은 15분간 접속이 없으면 잠들고, 다시 켜질 때 저장 파일이 사라질 수 있습니다.
> 세션이 끝나면 GM 화면 → **방 백업(JSON)** 으로 저장해 두고, 다음에 **백업 불러오기**로 복원하세요. (업로드한 이미지도 백업에 포함)
> 계속 유지하려면 Render 유료 디스크나 Railway / Fly.io 볼륨에 `DATA_FILE` 경로를 두면 됩니다.

환경변수: `PORT` (포트), `DATA_FILE` (저장 파일 경로, 기본 `data/rooms.json`).
