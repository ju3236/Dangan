# DANGAN RP — 단간론파 역극 사이트

친구들과 실시간으로 단간론파 스타일 역극(롤플레이)을 할 수 있는 사이트입니다.
**일상 파트 → 조사 파트 → 학급재판** 흐름을 그대로 진행할 수 있어요.

## 기능

| 파트 | 기능 |
| --- | --- |
| 공통 | 방 코드/초대 링크로 입장, 캐릭터(이름·초고교급 재능·이미지·이름 색·프로필) 생성, 대사/행동 지문, 주사위(`/r 20` 또는 🎲), 로그 텍스트 저장 |
| 일상 | 장소 목록과 현재 장소, 날짜(N일째), GM 나레이션, 모노쿠마 방송, 학생 수첩(프로필) |
| 조사 | 「시체 발견 방송」 연출, 모노쿠마 파일, 언령(증거) 입수·수정 — 모두가 공유 |
| 학급재판 | 논스톱 의논: 발언의 `{약점}`을 클릭해 언령을 쏘기(그건 틀렸어! / 동의한다!), GM이 정답 언령을 정해두면 자동 BREAK 판정, 아니면 GM이 직접 판정. 투표 시작 → 각자 투표 → 결과 공개 |
| GM | 파트 전환(연출 포함), 날짜·장소 관리, NPC 생성, 캐릭터 사망 처리, GM 넘기기, 방 백업/복원(JSON), 로그 초기화 |

- 방을 만든 사람이 GM입니다. 새로고침해도 같은 브라우저면 같은 사람으로 인식됩니다.
- 방 데이터는 서버의 `data/rooms.json`에 자동 저장됩니다.

## 로컬 실행

```bash
npm install
npm start
# http://localhost:3000 접속
```

같은 와이파이의 친구는 `http://<내 PC IP>:3000` 으로 들어올 수 있습니다.

## 인터넷에 올리기 (친구가 멀리 있을 때)

Node.js 서버가 필요하므로 GitHub Pages로는 안 되고, 아래 같은 무료 호스팅을 쓰면 됩니다.

**Render (추천)**
1. https://render.com 가입 → New → Blueprint → 이 저장소 선택 (`render.yaml`이 자동 설정)
2. 배포가 끝나면 나오는 `https://….onrender.com` 주소를 친구에게 공유

> 무료 플랜은 15분간 접속이 없으면 잠들고, 재시작 시 저장 파일이 사라질 수 있습니다.
> 세션이 끝날 때 GM 탭의 **방 백업(JSON)** 으로 저장해 두고, 다음에 **백업 불러오기**로 복원하세요.

Railway, Fly.io, 개인 서버 등 Node 18+ 가 돌아가는 곳이면 어디든 `npm start`로 실행됩니다.
포트는 `PORT` 환경변수, 저장 위치는 `DATA_FILE` 환경변수로 바꿀 수 있습니다.

## 진행 예시

1. GM이 방을 만들고 초대 링크(상단 방 코드 클릭)를 공유
2. 각자 캐릭터 생성 → 일상 파트에서 자유롭게 역극
3. GM: 캐릭터 「사망 처리」 → **시체 발견 방송** → 모노쿠마 파일 공개
4. 조사 파트: 장소를 돌며 언령 입수
5. GM: **학급재판 개정** → 논스톱 의논 발언 추가 (예: `범인은 {밤 10시}에 식당에 있었어!`)
6. 약점에 언령을 쏴서 논파 → **투표 시작** → **결과 공개** → 처형
